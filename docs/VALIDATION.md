# Проверка поставки v0.3.0

Дата: **21 октября 2026 года**. Входы проверки — только синтетические задачи генератора. CSV из приложенного архива хакатона не использовались.

## Выполнено

`python scripts/check.py`: **74 теста, OK**, 79.630 секунды в среде подготовки.

- Проверены 81 JSON fixture согласованных контрактов, запрет лишних полей и non-finite JSON.
- Проверены точная дедупликация, конкурентная идемпотентность, повтор и устаревший job event, направление метрик и сравнимость протоколов.
- Проверены публикация, порядок и ведущие нули id, изменение файла после проверки, запоздавший худший кандидат, конфликт версии, одинаковый CSV разных кандидатов и восстановление journal после replace до SQLite commit.
- Проверены Native tool-call/response-проводка через FakeTransport, ограниченное исправление JSON и отсутствие retry при HTTP 401. Сеть для этого не использовалась.
- Проверены маскирование ключей, отсутствие API-ключа в training env, неоднозначность путей, literal NA и duplicate CSV header, ограниченный LLM-профиль.
- Проверены отмена родителя и дочернего процесса, реальный таймаут с C24 → C15 → C13 release, worker-side memory watchdog и ошибка запуска процесса без утечки lease.
- Пройдены полные subprocess-запуски классификации, регрессии и бинарной задачи. Выходной CSV валиден; лучшие модели в двух первых сценариях улучшили локальную метрику относительно Dummy.
- Пройдены отказ LLM после baseline и искусственное сокращение бюджета после публикации: готовый CSV сохранён.
- Пройден запуск плоского платформенного ZIP: только корневые solution.py/requirements.txt копируются к синтетическому task.md; PYTHONPATH репозитория убран. Из cwd задачи проходит baseline и два исследователя с реальным обучением, оценкой, refit и публикацией. Модульные подпапки до старта отсутствуют.
- Проверены групповой holdout и разделение полных временных периодов.
- Проверены необязательный OPENAI_MODEL, документированный default и приоритет env, отсутствие зашитого endpoint и отсутствие требования модели у клиента.
- Проверены Budget has been exceeded в HTTP 429/403, остановка retry/следующих вызовов, обычный временный 429 с retry и сохранение baseline при исчерпании бюджета.
- Проверены локальные train/test при нескольких чужих sample_submission, привязка optional-файлов к выбранным данным, явный optional-путь и исключение runs/.venv из поиска условий.
- Проверены воспроизводимость байтов ZIP, точный официальный requirements.txt, состав собственного runtime и сохранение предыдущего архива при неудачной сборке.

Полный вывод unittest: `validation-unittest.log`.

## Следующий внешний прогон команды

1. Для локального прогона установить requirements.runtime.txt в чистую Python 3.12 среду или собрать Dockerfile. Точный официальный список requirements.txt отдельно проверяется в предоставленной среде платформы.
2. Запустить scripts/doctor.py и scripts/check.py на точных версиях.
3. Подключить значения OPENAI_* организаторов и проверить один небольшой live-запуск, включая JSON/tool-call формат конкретного сервиса.
4. Проверить CatBoost-рецепт и интерфейс официального контейнера.
5. После этого отправлять dist/solution.zip на платформу с учётом лимита сабмитов.

Live API, точный Docker-образ платформы и CatBoost фактически не запускались: ключ отсутствует, необходимые пакеты не установлены. Адреса прокси и модель теперь известны из инструкции; доступность сети/поведение live-сервиса не проверялись. Полный официальный requirements.txt побайтово сохранён, но его установка и совместимость всех пакетов здесь не подтверждены. Приложенный Dockerfile — подготовленная конфигурация локального прогона, а не утверждение о выполненной Docker-сборке. Это рабочий каркас для развития командой, не заявление о готовом соревновательном качестве.

## Дополнительные проверки v0.3

- Truncation с пустым content и частичными tool arguments на cap: удвоение max_tokens и запрет повтора на том же потолке.
- Отдельный HTTP timeout и бюджет диалога; heartbeat ожидания без дополнительных API-запросов.
- Атомарные token reservations, отсутствие overcommit и консервативное списание без выдуманного usage.
- Подробный human/JSON терминал и редактирование секретов; обновление .env без изменения credentials/WORK_DIR/LLM_MODE, с dry-run.
- Синтетический HGB с допустимыми параметрами и ранний отказ для early_stopping='off'; ExtraTrees, вложенный CPU limit и train-only обратимое преобразование цели.
- Раздельные семейства для двух исследователей, фактические параметры incumbent в контексте.
- Полный регрессионный subprocess-цикл с catalogue warmups до LLM-планов и сохранением общего лимита попыток.
- Совместимость исходных wire fixtures C00–C24; новый ResearchChoice-v1 и старый code-mode проходят общий Gateway.
- Новый prompts/researcher-catalog.md включён в плоскую сборку; весь packaged end-to-end тест прошёл.

Это не live-прогон v0.3 с Qwen или CatBoost и не новый замер публичного RMSE. Метрика 45.7758
относится к предоставленному запуску команды на v0.2. Для v0.3 нужно обновить настройки существующего
.env через scripts/configure.py --apply и повторить ту же задачу/валидацию, затем другие задачи.
Предоставленные исходные CSV при подготовке этой версии не анализировались.

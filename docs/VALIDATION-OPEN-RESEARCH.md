## Что проверяют новые сценарии

- Типы и пропуски сохраняются при переполнении контекста и добавлении схем/tool replies.
- Анализ использует fit-строки, возвращает агрегаты, сохраняет/читает отчёты по ID и не
  выдаёт target тестовой выборки при сравнении признаков.
- Ответ analyze_data используется следующим ответом LLM; произвольный составной pipeline
  проходит C09/G04 без подмены встроенной factory.
- Локальные продолжения требуют явного разрешения, соблюдают выбранные параметры,
  число попыток и срок; при недоступности API используется только собственный каталог.
- Измеренный успех признака не создаёт автоматическую обязательную ветку. Явно запрошенная
  контролируемая ветка по-прежнему соблюдает ограничения.
- Неконечные/зарезервированные параметры и чтение исходных файлов сгенерированным кодом
  отклоняются. Проверено сохранение штатных импортов и работы sklearn.
- Собственные модели действительно обучаются, оцениваются, публикуются и воспроизводятся
  из закреплённого runtime и исходного кода для обоих типов задач.
- Существующие сценарии проверяют группы процессов, deadline/RSS, сбои API/обучения,
  идемпотентность, откат транзакций, формат вывода и сохранение последнего проверенного CSV.

Исправлены две старые фикстуры: BACKTRACK получил обязательное поле action; проверка
повторного ResearchChoice-v1 явно выбирает catalog после смены режима по умолчанию.

## Среда и ограничения вывода

Python 3.12.14; pandas 2.2.3; numpy 2.3.5; scipy 1.17.0; scikit-learn 1.8.0;
joblib 1.5.3. Это доступная среда проверки, а не точное воспроизведение pinned-окружения
организаторов. CatBoost в ней отсутствует; новые сквозные проверки используют sklearn.

Вызовы LLM в проверках имитированы только для синтетических задач. Предоставленный API,
живая Qwen, public/private score и прирост от новой политики не измерялись. Результаты
подтверждают работоспособность интерфейсов и отсутствие выявленных регрессий, а не качество
автономного выбора гипотез. Python audit guard не объявляется OS-песочницей.

Для существующего `.env` новый путь включается явно: `RESEARCH_MODE=adaptive`.

# Архив исходной архитектуры

В этой папке сохранены исходные схемы, предложения и спецификации раннего устройства проекта.
Это исторический материал. Изображение или запись здесь не подтверждает, что все её элементы
реализованы в текущей версии.

Действующее объяснение находится в [PROJECT_GUIDE.md](../PROJECT_GUIDE.md),
действующая схема сообщений — в [contracts.schema.json](../../contracts/contracts.schema.json),
границы и причины последних изменений — в [ARCHITECTURE_REVIEW.md](../ARCHITECTURE_REVIEW.md).

Исходные [contracts.md](contracts.md), [PROTOCOL.md](PROTOCOL.md), [architecture.svg](architecture.svg)
и HTML-представления остаются доступны для сопоставления истории проекта. При разработке
сверяйте форматы с действующими производителями, потребителями и проверками.

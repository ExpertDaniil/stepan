## Пределы результата

- Это искусственные проверки и проверка устройства. Настоящего трёхчасового
  запуска с API и оценки на данных соревнования здесь нет.
- Архив проверяется воспроизводимой сборкой и запуском после копирования только
  корневых файлов. Загрузка и выполнение на внешней платформе не проверялись.
- Доступ к анализу ограничен сводками и временем; полный исходный профиль при
  подготовке по-прежнему читает таблицы целиком.
- Python-ограничитель и наблюдение памяти не являются отдельной изоляцией ядра ОС.
- Протокол проверки фиксирован. Независимый расчёт метрики не устраняет подгонку
  исследования под многократно используемую проверочную часть.
- Подборка оригинальных тетрадей пока узкая: два файла одного автора, четыре
  размеченных приёма. 154 текстовых разбора не равны 154 исходным `.ipynb`.
- Граф исправлен в конкретных местах; вся его внутренняя структура не переписана.

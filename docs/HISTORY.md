# Исторические материалы проекта

Действующее руководство — [PROJECT_GUIDE.md](PROJECT_GUIDE.md), причины новой архитектуры —
[ARCHITECTURE_REVIEW.md](ARCHITECTURE_REVIEW.md). Этот указатель отделяет результаты прежних проверок
и исходные предложения от текущей инструкции. Отчёты сохранены: их даты, оценки и ограничения полезны
для сравнения, но не описывают автоматически сегодняшний код.

| Материал | Как его использовать |
|---|---|
| [RESEARCH-REVIEW.md](RESEARCH-REVIEW.md) | Анализ ограничений и изменений раннего исследовательского интерфейса |
| [RUN-REVIEW-20261022.md](RUN-REVIEW-20261022.md) | Разбор конкретного запуска и последовавших исправлений |
| [RUN-REVIEW-ab9dbc6c.md](RUN-REVIEW-ab9dbc6c.md) | Наблюдения о поиске, памяти и согласованности на другом запуске |
| [VALIDATION.md](VALIDATION.md) | Проверка первоначальной реализации |
| [VALIDATION-CONSISTENCY.md](VALIDATION-CONSISTENCY.md) | Проверки согласованности версии своего выпуска |
| [VALIDATION-FINAL-REFINEMENT.md](VALIDATION-FINAL-REFINEMENT.md) | Испытания перехода к доводке в соответствующем выпуске |
| [VALIDATION-GRAPH.md](VALIDATION-GRAPH.md) | Проверки первоначальной версии графа |
| [VALIDATION-OPEN-RESEARCH.md](VALIDATION-OPEN-RESEARCH.md) | Проверки первого адаптивного интерфейса |
| [VALIDATION-PACKAGING.md](VALIDATION-PACKAGING.md) | Проверки плоской поставки определённого выпуска |
| [VALIDATION-RESEARCH.md](VALIDATION-RESEARCH.md) | Проверки исследования и параметров в предыдущей версии |
| [VALIDATION-RUN-REVIEW.md](VALIDATION-RUN-REVIEW.md) | Пределы проверки исправлений после разбора запуска |
| [Исходные схемы](architecture/README.md) | Замыслы и исходная спецификация; при расхождении проверять работающий код |

При чтении отчёта сначала установите его проверенный коммит, среду, режим исследования и вид данных.
Успех старой проверки не заменяет повторную проверку изменённого кода. Искусственные оценки,
измерения настоящих обучений и предположения авторов имеют разный смысл; он указан в самих отчётах.
